# Continuous Random Variables

$X$ is a continuous random variable if there exists a nonnegative function $f$ defined for all real $x \in (-\inf, \inf)$, haaving the property that for any set $\{ x \le a \}$ of real numbers.

$$
P(x \le a) = \int_{ x \le a } f(x) dx
$$

The function $f$ is the probability density function of the random variable $X$.

**Properties**:
$$
\begin{align*}
	f(x) &\ge 0  \qquad \text{ for all } x \in R(X) \\~\\
	\int_{R(X)}^a f(x) dx &= 1 \\~\\
	P\{ a < X < b \} &= \int_a^b f(x) dx \\~\\
	E(X) &= \int_{R(X)} x f(x) dx = \mu \\~\\
	Var(X) &= E(X^2) - \mu^2 \\~\\
	f(X &= a) \ne \text{Probability!}
\end{align*}
$$

> **Note**: For continuous random variables, equal-to inequality (e.g., $\le$ and $<$) are interchangeable.
