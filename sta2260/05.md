# Continuous Random Variables

$X$ is a continuous random variable if there exists a nonnegative function $f$ defined for all real $x \in (-\inf, \inf)$, having the property that for any set $\{ x \le a \}$ of real numbers.

$$
P(x \le a) = \int_{ x \le a } f(x) dx
$$

The function $f$ is the probability density function of the random variable $X$.

**Properties**:
$$
\boxed{
	\text{Cont.: }
	\begin{cases}
		f(x) &\ge 0  \qquad \text{ for all } x \in R(X) \\~\\
		\int_{R(X)}^a f(x) dx &= 1 \\~\\
		P\{ a < X < b \} &= \int_a^b f(x) dx \\~\\
		E(X) &= \int_{R(X)} x f(x) dx = \mu \\~\\
		Var(X) &= E(X^2) - \mu^2 \\~\\
		f(X &= a) \ne \text{Probability!}
	\end{cases}
}
$$

> **Note**: For continuous random variables, equal-to inequality (e.g., $\le$ and $<$) are interchangeable.

<details><summary>Example: Continuous R.V.</summary>
Q: A continuous r.v. $X$ has the pdf function:

$$
f(x) = \frac{1}{2}x + c \qquad 0 \le x \le 1
$$

Find the value of:
1. c
2. P(1/3 < X < 1/2)
3. E(X)
4. Var(X)
5. P(P>1/3 | X < 1/2)

A:

1.

We know $\int_{R(X)} f(x) dx = 1$; so:

$$
\begin{align*}
	1 &= \int_0^1 ( \frac{1}{2} x + c) dx \\~\\
	1 &= \left[ \frac{1}{4} x^2 + c \right]_0^1 \\~\\
	1 &= \frac{1}{4} + c \\~\\
	c &= \frac{3}{4}
\end{align*}
$$

2.

$$
\begin{align*}
	\int_{1/3}^{1/2} ( \frac{1}{2} x + \frac{3}{4}) &= ... \\~\\
	&= 0.1597
\end{align*}
$$
</details>

# Exponential Random Variable

Exponential distribution arises when looking at amount of time until some specific event occurs.

**Properties**:
$$
\boxed{
	\text{Exp.: }
	\begin{cases}
		f(x) &= \lambda e^{- \lambda x} \text{ where } x \ge 0 \\~\\
		E(x) &= \frac{1}{x} \\~\\
		Var(x) &= \frac{1}{x^2} \\~\\
	\end{cases}
}
$$

# Normal Random Variable

**Properties**:
$$
\boxed{
	\text{Normal: }
	\begin{cases}
		f(x) &= \frac{1}{ \sigma \sqrt{2 \pi} } e^{ - \frac{1}{2\sigma^2}(X-\mu)^2} \text{ where } -\inf < x < \inf \\~\\
		\text{Mean} &= \mu \text{ (location)} \\~\\
		\text{SD} &= \sigma \text{ (shape)} \\~\\
	\end{cases}
}
$$

**Standard Normal**: Z ~ N(0,1)
- We can use Z-table for this.

$$
\boxed{
	\text{Percentile as Stand. Norm.: } Z_\alpha = 100( 1 - \alpha )^\text{th} \text{percentile}
}
$$

$$
\boxed{
	\text{Transformation: } \\~\\
	\begin{align*}
		\frac{X - \mu}{\sigma} &= Z \sim N(0,1) \\~\\
		\sigma Z + \mu &= X \sim N(\mu, \sigma) \\~\\
	\end{align*}
} \\
\small\textit{ (if $X \sim N(\mu, \sigma)$) }
$$

# Empirical Rule

$$
\boxed{
	\bar x \pm k \times SD = (\bar x - k \times SD, \bar x + k \times SD)
}
$$

If the distribution is bell-shaped (symmetric and unimodal):
- About 68% of observations lie within 1 SD of the mean.
- About 95% of observations lie within 2 SD of the mean.
- About 99.7% of observations lie within 3 SD of the mean.

## Standardization (Z-Score)

**Z-Score**: Distance between an observation and the mean in units of SD.
- Unit-free

$$
\boxed{
	\text{Z-Score: } z = \frac{x - \bar x}{s}
} \\
\small\textit{if $z < 0$, $x < \bar x$} \\
\textit{if $z > 0$, $x > \bar x$} \\
$$

$$
\boxed{
	\text{Outlier: } |z| > 3
}
$$
