Goal: Approximate a function from a set of points.

> **Example**: Why? (Problem Statement)
> 
> Problem: You are given a set of points.
> 
> And want to build a function that behaves like what we think the underlying function behaves like.
> 
> We've already done this with polynomial interpolation, though polynomial interpolation has its issues.
> - e.g., If you have 100 points that follow a simple quadratic function like $y=x^2$, using Newton's method to construct a 99-degree polynomial isn't very useful
> 
> In these notes, we'll work in the other direction and just try to find the right $a,b,c$ for $ax^2 + bx + c$; or $m,b$ in a line, etc.

Deriving ???:

We want a curve that is "closest to" all the points.
- This means computing the distance between the point and the curve.

$$
\text{Cumulative Distance Function: }
\Psi_i = \sum_i | f(x_i) - y_i |
$$

> In the end, we'll be defining $\Phi$ as a vector of coefficients so we can combine it linearly, but for this example it's just a function.
> - Notation note: f is phi

This function is just the sum of the differences between the actual and estimated points.

> Suppose $f(x)=ax + b$.

We want to minimize this.

$$
\Psi_i = \sum_i | ax_i + b - y_i |
$$

- In other words, we want to find the point where $i$ is the least possible. 
	- In other other words, we want to derivate w.r.t. to the unknowns, this means taking a partial derivative because we have two unknowns. This doesn't work though, because we just get two constants.

Instead of minimizing distance, we can minimize the square of the distances.

$$
\Psi_i = \sum_i | ax_i + b - y_i |^2
$$

The partial derivative of psi w.r.t. a is:

$$
\frac{d \Psi}{d a} = \sum_i 2 ( ax_i + b - y_i  ) x_i \\
= \sum_i 2(ax_i^2 + bx_i - x_i y_i)
$$

$$
\frac{d \Psi}{d b} = \sum_i 2 ( ax_i + b - y_i  ) 1 \\
$$

To minimize, we make it equal to zero.

$$
0 = \sum_i 2(ax_i + b - y_i) \\
\text{skipping some steps...}
$$

Now we have a system of equations:

$$
a \sum_i x_i^2 + b \sum x_i = \sum_i y_i x_i
$$

$$
a \sum_i x_i + b \sum_i 1 = \sum_i y_i
$$
