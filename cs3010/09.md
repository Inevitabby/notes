# Taylor Series

If you have a continuous and differentiable function $f$ at $x_0$, we can rewrite $f(x)$ as 

$$
f(x) = \sum_{n=0}^{\infin} \frac{
	f^{(n)} (x_0) (x - x_0)^n
}{
	n!
}
$$
