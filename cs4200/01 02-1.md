# Agents

$$
	\text{Agent} = \text{Architecture} + \text{Program}
$$

**Agent**: Anything that can perceive its environment through sensors and acting upon the environment through actuators.

> **Examples** — Human agents, robotic agents, software agents.

# Terms

**Percept**: The agent's perceptual inputs

**Percept Sequence**: The complete history of everything the agent has perceived

**Agent Function**: Maps any given percept sequence to an action [$f: p* \to A$]
- **Agent Program**: Runs on the physical architecture to produce $f$.

**Performance Measure**: Objective criterion for success of an agent's behavior
- Should generally measure what you want, rather than how you think an agent should behave.

# Rationality

An agent should "**do the right thing**" based on what it can percieve and currently do.
- The right action is the one that will cause the agent to be most successful.

> **Example**: Robovac
> 
> Which performance measure is better for a robovac?
> 1. +1 score for every dirt cleaned within a time unit, or
> 2. +1 score for each clean square per time unit
> 
> The former measure would reward a robovac that sucks $\to$ dumps $\to$ sucks

## Rational Agent

For each possible [percept sequence]{.underline}, a rational agent should select an [action]{.underline} that is expected to maximize its [performance measure]{.underline}. <!--given the evidence provided by the percept sequence and whatever built-in knowledge the agent has.-->

> **Aside**: On Omniscience, Learning, and Autonomy
> 
> Rationality isn't omniscience; there is a different between expected and actual performance.
> 
> Agents are autonomous if their behavior is determined by experience (they can learn and adapt).
