# Problem Domain Driven Languages

There are a class of problems where we decide we need a language to sole them.
- This is one of the main driving forces behind the design of programming languags.

> **Example**:
> - John McCarthy wanted to formalized computer programs and work on AI, leading to LISP. This was at a time when FORTRAN was *the* programming language to use.
> - Dennis Ritchie was a systems programmer who made C to program a large mainframe. This was at a time when companies would buy one mainframe and share it among everyone

Domains that historically driven language design:
- Scientific COmputation
- AI
- Enterprise/Business
- Management/Systems programming
- Web Application

> **Aside**: The total number of programming languages in the world is probably in the thousands due to rarely-used domain-specific languages.
