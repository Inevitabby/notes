# MIPS

## CPU

**Register File**: 
- While Von Neumann has only an accumulator, MIPS has 32 registers
- **Prefixes**:
	* `R#`: Register
	* `M#`: Memory

**Control Unit**: All computer operations are controlled by the CU.
- Timing signals that govern the IO transfers and generated by the CU
- Usually distributed throughout the machine instead of standing alone.

**ALU**: Most computer operations are executed in the ALU of the process.
- Loads operands into memory
- Brings them to the processor
- Perform operation in ALU
- Store result back to memory or retain in the processor

**Memory Unit**: Store programs and data
- **Main Memory**: Volatile
	* Fast.
	* Processed in words (e.g., 4 bits at a time)
- **Secondary Storage**: Non-volatile
	* Larger and cheaper.

## Basic Operational Concepts

To perform a task, an appropriate program (list of instructions) is store in the memory.
- Individual instructions and brought from memory into the processor, which executes them.
- Data to be used as operands is also stored in the memory.

**A Typical Instruction**:
```assembly
ADD R0, M1
```
- What it does: `R0 <- R0 + M1`{.rtn}
