# Overview of Mass Storage

Disks are attached to the computer via I/O bus.

Magnetic disks provide bulk secondary storage.
- Tranfer Rate: Rate of data flow between drive and computer.
- Positioning Time: Seek Time + Rotational Latency
	* Seek Time: Time to move disk arm to desired cylinder.
	* Rotational Latency: Time for desired sector to rotate under disk head.
- Head Crash: When disk head makes contact with disk surface.

Solid state disks are smaller, cost more, are faster.

Magnetic tapes are relatively permanent and hold large quantities of data.
- Random access is way slower, but way cheaper; so good for backup and storage/transfer.

# Disk Scheduling

Disk bandwidth: Totla number of bytes transferred, divided by total time between first request and completion of last transfer.

When a process need I/O, it issues a system call that specified:
- Whether the operation is input or output.
- Disk address for the transfer.
- Memory address for the transfer.
- Number of sectors to be transferred.

OS maintains a queue of request, per disk/device.
- Idle disks can immediately work, but busy disks need a queue.
