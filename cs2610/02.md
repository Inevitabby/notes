# Systems of Authentication

**User Authentication**: Main concept of access control.
- User identifies themselves with a credential and is verified by the system.

# Common Auth Methods

**Password**: Something you [know]{.underline}.
- e.g., codeword, pin

**Token**: Something you [have]{.underline}.
- e.g., physical card with chip/magnetic stripe. 

**Biometric**: Something you [are]{.underline}.
- e.g., fingerprint, blood, iris

**Multifactor**: [Combination]{.underline} of something you know/have/are.
- Needs at least 2 factors

# SSO

**Single Sign On**: One set of credentials gives access to a host of services.
- e.g., college SSO gives access to email, Canvas, bookstore, library, enrollment, et cetera.
      - notice no single person provides everything (Instructure, Oracle PeopleSoft, Microsoft).

> **Remember**: SSO isn't the same as MFA, but generally we really want to secure SSO so we usually secure SSO with MFA.
